# Phase 6 — global integration

Turns Frost from "a session beside Omarchy" into a system that installs and
boots on its own, on a **fresh CachyOS Minimal base**. The in-place Omarchy
cutover of the master plan's Phase 8 does not apply: the chosen path is a clean
install via `bootstrap-cachyos`, and AUR uses `paru` (no hardened builder or
root helper — the master plan's "Track B" is dropped by decision, 2026-08-30).

## `frost-settings` scope (item 2)

Privileged or global content, built here but installed only by the clean
install:

- UWSM / Hyprland session integration and the SDDM entry;
- Hyprlock PAM — explicit module, no `nullok`, no bypass;
- global systemd units and drop-ins;
- `/etc` defaults as drop-ins / `.pacnew`, never overwriting another package's file;
- Btrfs / Snapper / Limine integration (pairs with Phase 7);
- Frost pacman hooks;
- sudoers reduced to exact commands and arguments.

- [x] complete package ownership; no unowned privileged write — `frost-settings`
  ships nothing another package owns; `frost-firstboot` reconciles the rest;
- [x] no AUR in `BOOTSTRAP`/`CORE` (`inventory-contract`); `paru` builds AUR as

## Out of scope: initramfs, splash and bootloader

Decision, 2026-08-30: the bootstrap does not touch `mkinitcpio.conf`, does not
regenerate an initramfs and does not read or write a bootloader. Frost ships no
Plymouth theme, so the hook it used to add would only have surfaced the CachyOS
splash that is already configured; the base's boot path is left as CachyOS built
it, and `install-contract` now fails if the script mentions any of it.

## Provider pinning

The first install attempt died on `jack2 and pipewire-jack are in conflict`.
`ffmpeg`, `mpv`, `obs-studio` and `portaudio` depend on the virtual `jack`, which
`jack2` and `pipewire-jack` both provide; alpm resolves depth-first in manifest
order, reaches `jack` through `ffmpegthumbnailer` long before it reaches
`pipewire-jack`, and `--noconfirm` takes the first candidate. The two then meet as
targets of one transaction, which `--ask=4` cannot resolve.

`FROST_PROVIDERS` settles every ambiguous virtual in the closure as its own
transaction, before anything that needs one: `jack` → `pipewire-jack`,
`pipewire-session-manager` → `wireplumber`, `opengl-driver` → `mesa`,
`vulkan-driver` → `vulkan-radeon` (the default was an NVIDIA stack), `ttf-font` →
`ttf-dejavu`, `tessdata` → `tesseract-data-eng`, `netcat` → `openbsd-netcat`.
`test/resolve-plan` resolves the whole set against the live CachyOS repositories
and fails if any rejected provider reappears.
