# Phase 6 — global integration

Turns Frost from "a session beside Omarchy" into a system that installs and
boots on its own, on a **fresh CachyOS Minimal base**. The in-place Omarchy
cutover of the master plan's Phase 8 does not apply: the chosen path is a clean
install via `bootstrap-cachyos`, and AUR uses `paru` (no hardened builder or
root helper — the master plan's "Track B" is dropped by decision, 2026-08-30).

## Deliverables

| # | Item | State |
|---|---|---|
| 1 | **`frost-meta`** — the package that pulls the approved set | **done** — `frost-pkgs/pkgbuilds/frost-meta/PKGBUILD`, generated by `tools/generate-frost-meta` from `frost-packages.json`; 177 Arch/Frost deps (no BOOTSTRAP, no AUR); built and signed as `2026.08.29.5-1` |
| 2 | **`frost-settings`** — privileged/global config | not started |
| 3 | **Repo publishing** — the signed Frost repo reachable from a fresh machine (URL or on the install media) | not started |

| 5 | **First-boot migrations** — versioned, idempotent, never run as root by a hook | not started |
| 6 | **Audit** — external-call and capability sweep, `frost verify` | not started |

## `frost-settings` scope (item 2)

Privileged or global content, built here but installed only by the clean
install:

- UWSM / Hyprland session integration and the SDDM entry;
- Hyprlock PAM — explicit module, no `nullok`, no bypass;
- global systemd units and drop-ins;
- `/etc` defaults as drop-ins / `.pacnew`, never overwriting another package's file;
- Btrfs / Snapper / Limine integration (pairs with Phase 7);
- Frost pacman hooks;
- sudoers reduced to exact commands and arguments.

## Gate 6

- complete package ownership; no unowned privileged write;
- no AUR in `BOOTSTRAP`/`CORE`; `paru` builds AUR as the unprivileged user;
- `bootstrap-cachyos` runs on a clean CachyOS Minimal and yields a system that
  boots into Frost;
- PAM, Polkit and notifications each have a single owner;
- personal config survives an upgrade / reinstall;
- `frost verify` and the security tests pass.
